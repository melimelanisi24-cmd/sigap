# Database SIGAP

Aplikasi SIGAP menggunakan Supabase sebagai sumber data aktif untuk autentikasi,
profil, wilayah, pengaduan, aspirasi, lampiran, kategori, dan riwayat.

Ikuti [panduan Supabase](../supabase/README.md) untuk menyiapkan database aktif.
`sigap.sql` hanya berisi skema MySQL lama untuk referensi/migrasi; jangan impor
file tersebut sebagai database aplikasi aktif. Tidak ada akun atau data contoh
yang dibuat oleh skema ini.
